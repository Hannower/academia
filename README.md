# 🏋️ Two Training - Academia

Um projeto de *landing page* simples e responsiva para uma academia fictícia, a "Two Training". O objetivo é apresentar as modalidades, planos e informações de contato de forma clara e visualmente atraente.

## 🔗 Demonstração Online

Você pode acessar a versão hospedada do projeto através do GitHub Pages:

**[https://hannower.github.io/academia/](https://hannower.github.io/academia/)**

---

## ✨ Funcionalidades

O site é uma página única (*Single Page Application* - SPA) com navegação fluida por seções (links de âncora):

* **Banner Principal:** Apresentação com chamada de ação ("Comece agora!").
* **Home (`#home`):** Seção de boas-vindas e introdução à academia.
* **Modalidades (`#modalidades`):** Cards visuais para Musculação, Crossfit e Funcional.
* **Planos (`#planos`):** Apresentação de três opções de planos (Básico, Plus e Premium) com preços e detalhes.
* **Contato (`#contato`):** Informações de contato via WhatsApp.
* **Sobre (`#sobre`):** Descrição da missão e foco da academia.
* **Mapa (`#mapa`):** Localização integrada via `<iframe>`.
* **Navegação Fixa:** Menu superior (`<header>`) fixo e transparente que acompanha a rolagem.

## 💻 Tecnologias Utilizadas

O projeto foi construído utilizando as tecnologias fundamentais do desenvolvimento web:

| Tecnologia | Finalidade |
| :--- | :--- |

## 🎨 Design e Estilo

O projeto utiliza um design *dark* (escuro) com cores vibrantes para contraste.

**Paleta de Cores (Variáveis CSS):**

| Variável | Valor | Descrição |
| :--- | :--- | :--- |
| `--cor-principal` | `#d94fff` | **Roxo/Magenta** - Destaque em títulos. |
| `--cor-destaque` | `#ff447f` | **Rosa Forte** - Chamadas de ação (CTA). |
| `--cor-04` | `#1a1e27` | Fundo principal escuro. |
| `--cor-01` | `#f9f9f9` | Cor primária para textos. |

## 🚀 Como Executar Localmente

Siga os passos abaixo para ter uma cópia local do projeto rodando:

1.  **Clone o repositório (via HTTPS):**
    ```bash
    git clone [https://github.com/hannower/academia.git](https://github.com/hannower/academia.git)
    ```
2.  **Navegue até a pasta do projeto:**
    ```bash
    cd academia
    ```
3.  **Abra o arquivo:**
    Simplesmente abra o arquivo `index.html` em seu navegador.
